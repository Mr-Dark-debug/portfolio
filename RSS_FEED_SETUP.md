# Blog feeds

The public feed is generated by `app/rss.xml/route.ts` from the same published-post repository as the blog. `/api/rss` is a compatibility alias. Both are refreshed hourly. Drafts and future-dated posts are excluded, and every article URL uses the canonical domain and English locale.

Do not generate a separate `public/rss.xml`: it would conflict with the live route and omit database edits. The old generator command is retained only for compatibility with development watch scripts.
